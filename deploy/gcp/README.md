# Deploying sal-pub to GCP (GKE)

Terraform/OpenTofu configuration that runs the same stack as `docker-compose.yml` on Google Cloud.
Commands below use `tofu`; `terraform` works the same.

| Compose service | On GCP |
|---|---|
| `caddy` | Deployment behind a `LoadBalancer` Service on a reserved static IP. Same image and Caddyfile, so routing (`/auth/*`, `/.well-known/openid-configuration`) is unchanged. Caddy gets Let's Encrypt certificates itself and keeps them on a 1 GiB persistent volume. |
| `salpub` | Deployment (`salpub_replicas`, default 2) and a `salpub:8000` Service. |
| `keycloak` | Deployment (1 replica) and a `keycloak:8080` Service, which sal-pub uses for OIDC discovery. |
| `postgres` | Cloud SQL for PostgreSQL 17 on a private IP, with the `keycloak` and `salpub` databases. Backups and point-in-time recovery are on. |

The cluster is GKE Autopilot (regional) in its own VPC, with a least-privilege node service
account. Images live in Artifact Registry.

## Prerequisites

- A GCP project with billing, and permission to create the resources above (Owner, or Editor plus
  Project IAM Admin).
- `gcloud`, `docker` with `buildx`, and `tofu` (≥ 1.6) or `terraform`.
- A hostname you control DNS for.
- A private GCS bucket for Terraform state. The state contains the generated database, Keycloak
  admin, client and session secrets.

```sh
gcloud auth login
gcloud auth application-default login
gcloud storage buckets create gs://<state-bucket> --project <project> --location <region> \
  --uniform-bucket-level-access --public-access-prevention
```

## First deployment

```sh
cd deploy/gcp
cp terraform.tfvars.example terraform.tfvars      # set project_id, hostname, image_tag, IdPs
tofu init -backend-config="bucket=<state-bucket>" -backend-config="prefix=sal-pub"

# 1. Create the image registry first, so there is somewhere to push to.
tofu apply -target=google_project_service.apis -target=google_artifact_registry_repository.images

# 2. Build and push the three images (linux/amd64, also from Apple Silicon).
./build-images.sh <region>-docker.pkg.dev/<project>/salpub <image_tag>

# 3. Create everything else: network, cluster, database, workloads. Takes 15–20 minutes.
tofu apply
```

Then:

1. **DNS:** create an `A` record for `hostname` pointing at `tofu output static_ip`. Caddy requests
   a certificate once the name resolves; watch it with
   `kubectl -n salpub logs deploy/caddy`.
2. **kubectl:** run the command from `tofu output get_credentials`.
3. **Keycloak admin:** `https://<hostname>/auth/admin`, user `tofu output keycloak_admin_username`,
   password `tofu output -raw keycloak_admin_password`.
4. **Identity providers:** register `https://<hostname>/auth/realms/sal/broker/<alias>/endpoint`
   as the redirect URI with each provider (GitHub, Google, …). See `docker/keycloak/README.md`.

## Updating

Build with a new tag, set `image_tag` to it, and apply:

```sh
./build-images.sh "$(tofu output -raw registry)" v2
tofu apply -var image_tag=v2
```

sal-pub runs its database migrations on start. The Keycloak realm is imported only on its very
first start (`--import-realm` skips an existing realm), so later changes to
`docker/keycloak/sal.json` or `identity_providers` must be made in the admin console.

## Good to know

- **Hostname is permanent.** Actor IDs are built from it; changing it breaks federation for existing
  users.
- **Secrets** are generated by Terraform, stored in its state and passed to the pods as Kubernetes
  Secrets. Moving them to Secret Manager is a possible next step.
- **Database traffic** stays on the VPC's private IP, but isn't TLS-encrypted
  (`sslmode=disable`, as in Compose).
- **Single pods:** Keycloak (no clustering configured) and Caddy (owns the certificate volume) run
  one replica each, so restarts briefly interrupt login or all traffic.
- **Tearing down:** set `deletion_protection = false` and apply before `tofu destroy`. The Cloud SQL
  instance and its backups are deleted with it.
- **Cost:** you pay for Autopilot pod requests (about 1.75 vCPU and 2.75 GiB with the defaults),
  the Cloud SQL instance, the load balancer and the static IP. Check the GCP pricing calculator for
  your region.
